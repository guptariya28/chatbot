How these numbers are calculated

  1. Which items count? Business Confirmation = Must to Have, Tech Module is one of the ticked modules, Delivery Date is one of the ticked values (same as the filters of the Excel pivot). → {{ result.scope_count }} items
  2. Required = sum of Total Effort of those items = {{ "{:,.1f}".format(result.required_man_days) }} man-days ÷ {{ result.per_fte|round(2) }} = {{ "%.2f"|format(result.required_fte) }} FTE
  3. Available = {{ "{:,.1f}".format(result.available_man_days) }} man-days ÷ {{ result.per_fte|round(2) }} = {{ "%.2f"|format(result.available_fte) }} FTE (typed by PMO below; will come from the FTE sheet later)
  4. Deficit = Available − Required = {{ "{:,.1f}".format(result.deficit_man_days) }} man-days = {{ "%.2f"|format(result.deficit_fte) }} FTE
  5. Packaging possible = items above marked MS/MT PKG = {{ "{:,.1f}".format(result.package_man_days) }} man-days ÷ {{ result.per_fte|round(2) }} = {{ "%.2f"|format(result.package_fte) }} FTE
  6. Deficit after packaging = Deficit + Packaging = {{ "%.2f"|format(result.deficit_fte) }} + {{ "%.2f"|format(result.package_fte) }} = {{ "%.2f"|format(result.deficit_after_package_fte) }} FTE
  7. Delivered before April 2026 (Must to Have, dates in 2025 or Jan–Mar 2026): {{ result.before_count }} items, {{ "{:,.1f}".format(result.before_man_days) }} man-days = {{ "%.2f"|format(result.before_fte) }} FTE
  8. Dropped (Must to Have, Delivery Date = "Drop"): {{ result.dropped_count }} items, {{ "{:,.1f}".format(result.dropped_man_days) }} man-days = {{ "%.2f"|format(result.dropped_fte) }} FTE
